# License

Mobitty is licensed under the [Business Source License 1.1](https://github.com/mobitty/mobitty/blob/main/LICENSE) (BSL-1.1).

## What this means

- **Free for personal, non-commercial use**
- **Commercial use** requires a [purchased license](/pricing) during the BSL period
- **Converts to GPLv2+** four years after each release — every version eventually becomes fully open source

## Why BSL?

BSL lets us share the source code openly while sustaining development. Commercial deployments need a [purchased license](/pricing) to fund continued development.
