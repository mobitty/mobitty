# Installation

Use your favourite Node.js package manager to install globally — `mobitty` will be available as a command.

```sh npm
npm install -g mobitty
```

```sh pnpm
pnpm add -g mobitty
```

```sh yarn
yarn global add mobitty
```

## Requirements

- Node.js 18 or later
- A modern browser (Chrome, Firefox, Safari, Edge)
