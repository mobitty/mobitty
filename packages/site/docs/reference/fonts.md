# Fonts

Mobitty ships with 13 monospace font options. All fonts except System Default are [Nerd Font](https://www.nerdfonts.com/) variants loaded from the official Nerd Font CDN, which means they include icons and powerline glyphs out of the box.

## Available fonts

| Font | Family |
|------|--------|
| **Cascadia Code Nerd Font** (default) | CaskaydiaCove NFM |
| 0xProto Nerd Font | 0xProto Nerd Font Mono |
| DejaVu Sans Mono Nerd Font | DejaVuSansM Nerd Font Mono |
| Fira Code Nerd Font | FiraCode Nerd Font Mono |
| Geist Mono Nerd Font | GeistMono Nerd Font Mono |
| Hack Nerd Font | Hack Nerd Font Mono |
| Iosevka Term Nerd Font | IosevkaTerm NFM |
| JetBrains Mono Nerd Font | JetBrainsMono NFM |
| Meslo LG S Nerd Font | MesloLGS Nerd Font Mono |
| Source Code Pro Nerd Font | SauceCodePro NFM |
| Ubuntu Mono Nerd Font | UbuntuMono Nerd Font Mono |
| Victor Mono Nerd Font | VictorMono Nerd Font Mono |
| System Default | Consolas, Liberation Mono, Menlo, Courier |

## Custom fonts

You can enter any CSS `font-family` string in the profile settings. If the font is already installed on your device or loaded by another stylesheet, Mobitty will use it directly. No CDN loading occurs for custom font family values.
