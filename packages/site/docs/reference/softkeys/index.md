# Soft Keys

Soft keys are the customizable buttons at the bottom of the terminal screen. They provide quick access to modifier keys, navigation, macros, and tools — especially useful on mobile where a physical keyboard is not available.

![Soft key customization settings showing profile tabs, key layout editor, and custom key definitions](/img/softkey-setting.webp)

## Layout

The soft key bar is configured per profile. Each profile defines which keys appear on the bar. On desktop, the default layout is minimal (system meter and inline input). On mobile, the default includes modifier keys, navigation, and an expandable container with additional keys.

## Key types

- **Modifier keys** — Ctrl, Alt, Shift. These toggle on/off and apply to the next key you press.
- **Navigation and special keys** — Esc, Tab, arrow keys, Home, End, Page Up/Down, Enter, Space. Arrow keys and scroll keys support hold-to-repeat.
- **Input controls** — Batch input panel, inline input for entering longer text, and paste for quick clipboard insertion.
- **System meter** — Toggles the connection health overlay.
- **Custom keys** — User-defined macros that send key combinations (e.g. Ctrl+C, or multi-step sequences).
- **Containers** — Expandable groups that hold additional keys in a slide-up panel.

## Customization

Soft keys are fully customizable in the settings panel. You can add, remove, and reorder keys, create custom macros, and organize keys into containers.
