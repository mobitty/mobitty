# Themes

Each profile references two themes — one for light mode and one for dark mode. Mobitty follows your OS colour scheme preference automatically. You can create new themes from the settings menu.

## Built-in themes

| Theme | Variant | Credit |
|-------|---------|--------|
| Default | dark / light | — |
| Dracula | dark | Dracula Theme |
| Nord | dark | Arctic Ice Studio |
| Gruvbox | dark / light | morhetz |
| Catppuccin Mocha | dark | Catppuccin |
| Catppuccin Latte | light | Catppuccin |
| Tokyo Night | dark | Enkia |
| One Dark | dark | Atom |
| Solarized | dark / light | Ethan Schoonover |
| Tango | dark / light | freedesktop.org |
